# Six-pillar audit v3

Separate research revision based on v2. Earlier suites/evidence remain unchanged. Audit scope is the current user's six-pillar request, not a claim that all additions were instructor-mandated Week 1 production choices.

| Pillar | Implemented and tested contract | Research/external limits |
|---|---|---|
| Curriculum | Exact valid-token budgets, adaptive accumulation, target trimming, smooth aux/temperature/mixture ramps, coupled WSD, document positions/masks, checkpointable slice sampling and held-out excess-loss feedback | Seq length changes at stage boundaries; observed token mixture can differ from sampling probabilities; full DoReMi proxy/reference training not reproduced |
| MoE | Shared experts/dense prefix, switch/bias/hybrid modes, unbiased gate weights, one detached controller commit per global update, padding exclusion, deterministic capacity masks | Dense all-expert reference execution, no sparse/EP kernel; controller uses pre-capacity demand so drops cannot hide imbalance |
| Universal attention / KV | GQA, MHA, MQA, MLA, sliding-window hybrid, differential reference mode; independent QK/V widths; MLA latent/query ranks and no-RoPE/RoPE split; RoPE scaling, local/global schedule, learned sinks and group KV sharing. Model-level eval/no-grad cache decode matches prefix recomputation in tests. | These are correctness-first dense PyTorch implementations, not fused/optimized kernels; differential mode is a compact reference variant, not a claim of full paper reproduction. Cache-byte metric is a per-layer payload estimate and omits metadata/sink storage. |
| Stability / G4 / scaling | QK norm, smooth optional caps, empirical lookup variance guard, shape-checked provider adapter and width projection, explicit untied dense, dynamically tied KE and chunked factorized KE heads, width init/attention/readout/LR hooks, four optimizer roles | G4 implementation not delivered; no analytic independent-factor variance claim; no certified muP transfer, especially with Muon; expensive optional tied full-vocab output |
| Operational traps | Native/callback RNG isolation, checkpoint model/optimizer/WSD/curriculum/controller/sampler/RNG/history/provenance, separate held-out metrics, explicit G7 pending-size mode | Same-environment bitwise guarantee only; no distributed resume engine; arbitrary custom providers must meet state/checkpoint contract |
| Config contracts | Every base YAML setting has a comment source; schema covers all leaves and tiny overrides. Dedicated precision/checkpoint/evaluation, scheduler, MTP, 4D parallelism, FFN, grouping/scoring, packing/FIM and head-mode fields are explicit. | 4D topology and ZeRO are contracts only; local runtime rejects non-single-process execution. FIM nonzero is rejected until a tokenizer/data marker contract exists. |
| G8 / plan | Exact metric names/formulas/labels, per-layer KV/cache and hybrid diagnostics, update-level routing aggregation, operational evidence, quantitative arms and budgets | Temporal alarm calibration and TSAI approval remain pending |
| Verification | Existing tests retained with one updated KE shape assertion reflecting newly valid width-adapter behavior; new mathematical/unit attention-mode/cache and full fresh-process repeat/resume/XAI tests | Fixture learning does not establish capability; real-data step losses need not be monotonic |
